# Trip8 Mobile App 🌄

Trip8 is a React Native mobile application designed for discovering, customizing, and booking travel packages across North-East India. Travelers can browse curated trip itineraries, request custom quotes from verified local travel operators, and book trips with transparent pricing.

---

## 🚀 Key Features

- **Curated Tour Packages**: Explore detailed itineraries across Assam, Meghalaya, and Arunachal Pradesh.
- **Custom Quote Requests**: Submit travel preferences, dates, and group size to receive quotes from local operators.
- **Multi-Step Booking**: Select dates, travelers, and room preferences with itemized price breakdowns.
- **Light & Dark Theme**: Built-in dynamic theme switching.

---

## 🛠️ Tech Stack

- **Framework**: [Expo SDK 57](https://expo.dev) + [React Native 0.86](https://reactnative.dev)
- **Language**: [TypeScript](https://www.typescriptlang.org)
- **Navigation**: React Navigation v7 (`Native Stack` & `Bottom Tabs`)
- **Styling**: NativeWind v4 (TailwindCSS) + Reanimated
- **State**: Zustand

## 💻 How to Run the Project

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- **Expo Go** app on your phone OR an Android/iOS emulator installed

### Steps

1. **Clone the repository**:
   ```bash
   git clone [https://github.com/manavsharmah/trip8-demo.git]
   cd Trip8-mobile-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. **Launch on device or emulator**:
   - Press **`a`** to open in **Android Emulator**
   - Press **`i`** to open in **iOS Simulator**
   - Press **`w`** to open in **Web Browser**
   - Or scan the terminal QR code using **Expo Go** on your device
